# AI Jira Ticket Assistant

Enter a Jira ticket key and get an AI-generated implementation plan: summary, unclear requirements, acceptance criteria, subtasks, suggested files/components, implementation approach, test cases, QA checklist, a draft completion comment, and a complexity estimate — with an optional button to post the draft comment back to the real ticket.

This is the MVP described in the project scope doc. It does **not** read your actual codebase or open pull requests (that's the "even better version," a future extension).

## Setup

1. Install dependencies:
   ```
   npm install
   ```

2.   the env template and fill in real values:
   ```
   cp .env.local.example .env.local
   ```

   - `JIRA_BASE_URL`, `JIRA_EMAIL`, `JIRA_API_TOKEN` — your Jira Cloud site and an API token from [id.atlassian.com → Security → API tokens](https://id.atlassian.com/manage-profile/security/api-tokens).
   - `ANTHROPIC_API_KEY` — from the [Anthropic Console](https://console.anthropic.com/).
   - `ANTHROPIC_MODEL` — defaults to `claude-sonnet-5`.
   - `DATABASE_URL` — local SQLite file, defaults to `file:./dev.db`.

3. Apply the database schema (creates `prisma/dev.db`):
   ```
   npx prisma migrate dev
   ```

4. Run the dev server:
   ```
   npm run dev
   ```
   Open http://localhost:3000 (or whatever port is printed if 3000 is busy).

## How it works

- Enter a ticket key (e.g. `WEB-1245`) → the app fetches it from Jira, sends the summary/description to Claude, and renders the structured analysis.
- Every analysis is saved, so past runs are listed in the sidebar and can be revisited without re-calling the AI.
- The draft completion comment is editable before posting; posting to Jira is a separate explicit action and never happens automatically.

## Notes

- No automated tests yet — verification for this MVP is manual (see the plan in `.claude` history, or just run through the flow above with a real ticket).
- `src/generated/prisma` is generated by `prisma generate` and is gitignored.
